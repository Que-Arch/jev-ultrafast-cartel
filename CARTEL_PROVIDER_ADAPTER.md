# CARTEL decision-provider adapter

Jev keeps its original TypeSafe route by default, but CARTEL can use any OpenAI-compatible JSON provider without changing the browser/action safety layer.

## TypeSafe (upstream default)

```text
JEV_DECISION_PROVIDER=typesafe
TYPESAFE_API_KEY=[REDACTED]
```

## OpenAI-compatible provider

```text
JEV_DECISION_PROVIDER=openai-compatible
JEV_DECISION_API_KEY=[REDACTED]
JEV_DECISION_BASE_URL=https://api.example.com/v1
JEV_DECISION_MODEL=provider-model-name
```

The adapter appends `/chat/completions` when needed and requires JSON containing Jev's `answers` object. Invalid responses fail closed before any browser action.

## CARTEL boundary

- The provider chooses only among observed browser operations and targets.
- Browser code owns target validation, stale-page checks and execution.
- No selectors, coordinates, JavaScript, shell commands or arbitrary URLs are generated by the model.
- Keep `JEV_DECISION_API_KEY` in process environment or a secret manager only; never commit it.
- Start with public read-only allowlisted sources.
- Publication, customer messaging, payments, commerce, trading and authenticated browser sessions remain outside this pilot.
